# DexDisplay
### Your glucose. At a glance.

**🚧 Coming Soon — Currently in Development**

DexDisplay is a free, open-source bedside glucose display powered by the Raspberry Pi 5. Developed by **NextFrame Labs**, DexDisplay aims to provide a simple, modern way to view glucose readings and trends using the Dexcom API.

### ✨ Planned Features
- 📊 Glucose readings and trend graphs
- 🌙 Apple StandBy-inspired bedside interface
- 🎨 Customizable themes, including a dim red night mode
- 📱 Mobile companion app for settings and customization
- 🕒 Clock, date, and other useful widgets
- 🔄 Automatic data updates
- 🖥️ Fullscreen Raspberry Pi experience

### 🚀 Development Status

DexDisplay is currently in early development. The software is not yet available for public use.

Stay tuned for updates, development progress, and our first official release!

### ⚠️ Disclaimer

DexDisplay is an independent project and is not affiliated with, endorsed by, or sponsored by Dexcom. It is intended as a secondary information display and should not replace official glucose monitoring devices, alerts, or medical guidance.
